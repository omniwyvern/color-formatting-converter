This is a simple converter tool to help a friend convert strings of the format
[color=#896BFF]Ｔ[/color][color=#8672FF]Ｒ[/color][color=#837AFF]A[/color]
to the format
{col:896BFF}T{/col}{col:8672FF}R{/col}{col:837AFF}A{/col}

It's to change the color of custom text (I think for housing in WoW? Maybe.) to be in a usable format.
